How it works

Three steps, about ten seconds.

1

Pick a source

Books or Quotes practice sites, or paste a public page with a table.

2

Scrape politely

One request per second, robots.txt checked first, 20 pages max.

3

Download

CSV (opens Arabic correctly in Excel) or a real .xlsx file.

Built to stay on the right side

Scraping tools get sites banned. This one has guard rails built in.

🤖

Obeys robots.txt

If the site says no, it stops.

⏱

Rate limited

1 request per second per site, plus per-visitor limits.

🛡

Blocklist

Alibaba, AliExpress, Amazon, social networks and private addresses are refused.

🔒

No personal data

Built for public data. Nothing is stored on the server.
