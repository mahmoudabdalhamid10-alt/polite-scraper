Pick a source or paste a public page. Get a clean CSV or XLSX in seconds. Built to be polite: it obeys robots.txt, waits between requests, and refuses sites that forbid scraping.

Ready. Each page takes about a second, so 5 pages is roughly 5 to 8 seconds.
🤖

Obeys robots.txt

Checked before every request. If the site says no, it stops.

⏱

Rate limited

One request per second per site, 20 pages max per run.

🛡

Blocklist

Alibaba, AliExpress, Amazon and social networks are refused. So are private addresses.

🔒

No personal data

Built for public, non-personal data. Nothing is stored on the server.

Custom URL mode reads the first table on the page, or the page links when there is no table. Please use it only on pages you are allowed to collect.
